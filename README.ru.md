# Git Contribution Analyzer

[English](README.md)

Python-скрипт запускает `git blame` для отслеживаемых файлов и показывает распределение строк по авторам или группам. Это атрибуция строк в текущем рабочем дереве, а не сумма всех добавленных за историю строк и не показатель личной продуктивности.

## Требования

- Python 3 и Git в `PATH`.
- `pandas` и `matplotlib`.
- Git-репозиторий с каталогом `.git`: текущая проверка не поддерживает связанные worktree, где `.git` — файл.

```bash
python -m pip install pandas matplotlib
python git_stat_script.py /path/to/repository
python git_stat_script.py /path/to/repository --grouping-file /path/to/grouping.txt
```

Без `--grouping-file` скрипт ищет `grouping.txt` рядом с собой. Пустые строки и строки с `#` в начале игнорируются. Формат группировки:

```text
Команда A: Alice, Alice Smith
Команда B: Bob
```

Программа выводит таблицу, столбчатую и круговую диаграммы. В больших репозиториях обработка может занять много времени: для каждого отслеживаемого файла выполняется `git blame`; файлы с ошибками пропускаются. Имена сопоставляются с полем `author` Git. Команды и графический вывод в текущем окружении не проверялись.
